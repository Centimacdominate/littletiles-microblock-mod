# LittleTiles — Micro-Block Building Mod

[![Download Latest](https://img.shields.io/github/v/release/Centimacdominate/littletiles-microblock-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Centimacdominate/littletiles-microblock-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Place blocks at 1/16th scale to create incredibly detailed structures, furniture, and decorations.

![LittleTiles — Micro-Block Building Mod Preview](https://cdn.modrinth.com/data/RCRxC1tD/images/aaa49695dbeb5ed922502868fbaea16b94918e7a_350.webp)

## Features

- Sub-block placement at 1/16 tile precision
- Hundreds of built-in tile shapes: slopes, pillars, arches
- Animate tiles with doors, panels, and drawer behaviour
- Chisel & Bits style with animated moving parts
- Blueprint system to save and share structures

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
